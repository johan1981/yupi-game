# Nexus Breuk — ChatGPT session image manifest

Deze map/index hoort bij de verhaalcanon die op 2026-09-30 uit de ChatGPT-sessie is vastgelegd.

## Goedgekeurde visuele richting
- cinematic 3D game/comic
- Nederlandse tekstkaders
- blauw/oranje Nexus-belichting
- character consistency volgens Game Bible en YUPI_SPEC

## Gegenereerde beelden uit de sessie
De lokale ChatGPT-sessie bevat onder meer:
- Yuno en de gebroken tijdsband
- aankomst bij Arqion / zwevende stad
- Arqion level 7 comic
- Yupi-varianten roster
- Level 8 — De Doorbraak
- Level 9 — Het Geheim van Prime
- Level 10 concept / De Oorsprong
- Y.V. als pup / Y-00 / Project PRIME
- eerdere conceptbeelden van Yupi Prime, Echo Yupi, Nox, Aqua-X en wereldkaarten

**Belangrijk:** de GitHub-connector kan in deze chat UTF-8 repositorybestanden schrijven, maar kan de lokale PNG-binaries uit de ChatGPT-sessie niet rechtstreeks uploaden. Daarom is de verhaalcanon nu wél rechtstreeks in de repo vastgelegd; de PNG-bronbestanden moeten via een binaire uploadroute aan deze map worden toegevoegd zodra die beschikbaar is.
