# Adult Yupi assets

Adult Yupi is the older form that follows Teen Yupi.

## Hard anatomy

Adult Yupi inherits the canonical Yupi anatomy/laterality from:
- `docs/characters/YUPI_SPEC.md`
- `docs/characters/YUPI_SPEC.json`

Hard rules:
- exactly 3 legs;
- right foreleg present;
- left foreleg completely absent to the shoulder;
- no stump or nub;
- both hindlegs present;
- right ear upright;
- left ear floppy;
- no automatic mirroring.
