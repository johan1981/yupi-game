# Yupi motion references

Approved real-Yupi movement references live here as repo metadata.

Large original videos may be kept in the managed ChatGPT Library while this public repository stores:
- a stable reference id;
- source filename and hash;
- source properties;
- approval status;
- movement observations that must guide animation.

These references are movement sources only. They never override `YUPI_SPEC.md`, `YUPI_SPEC.json`, or the approved visual base design.
