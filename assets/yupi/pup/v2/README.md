# Pup Yupi v2 — officiële visuele referentie

Deze map bevat de goedgekeurde visuele basis voor Pup Yupi.

## Leidend bestand

- `character-sheet.png`

## Harde anatomische regel

Yupi heeft **exact drie poten**:

- twee achterpoten;
- één rechter voorpoot;
- de linker voorpoot ontbreekt volledig tot aan de schouder.

Er mag nooit een stomp, gedeeltelijke linker voorpoot, extra poot of verborgen vierde poot worden toegevoegd.

## Gebruik

Nieuwe idle-, walk-, run-, jump- en andere sprites moeten qua kop, oren, lichaamsverhoudingen, vacht en anatomie op deze v2-sheet aansluiten.

De bestaande walk-tests blijven technische bewegingsreferenties totdat nieuwe v2-bewegingssprites zijn goedgekeurd.
