# Approved poses

Alle bestanden in deze map zijn expliciet goedgekeurde Yupi Pup-posebronnen.

Structuur: `poses/<pose>/<view>.png`, waarbij `view` één van `front`, `right`, `left`, `back` is.

Een pose wordt hier alleen toegevoegd na expliciete goedkeuring (`vastleggen`, `vastzetten`, `opslaan`).
