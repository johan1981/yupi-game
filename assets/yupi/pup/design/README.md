# Design

`approved/base-reference.jpg` is de **actuele, expliciet goedgekeurde visuele basis** voor Pup Yupi.

Deze referentie heeft voorrang op oudere V2-designs. Het eerdere V2-blad is gearchiveerd onder `archive/legacy-v2/base-sheet.png`.

Nieuwe poses, sprites en illustraties moeten qua kop, snuit, ogen, vacht, verhoudingen, staart en vaste asymmetrie op deze referentie aansluiten.

De harde anatomische regels komen altijd uit `docs/characters/YUPI_SPEC.md` en `docs/characters/YUPI_SPEC.json`.
