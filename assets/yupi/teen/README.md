# Teen Yupi assets

This folder tracks approved **Teen Yupi** visual assets.

## Hard anatomy

Teen Yupi inherits the canonical Yupi anatomy and laterality from:

- `docs/characters/YUPI_SPEC.md`
- `docs/characters/YUPI_SPEC.json`

That means:

- exactly 3 legs;
- right foreleg present;
- left foreleg absent completely to the shoulder;
- no stump;
- both hindlegs present;
- right ear upright;
- left ear floppy;
- no automatic mirroring.
