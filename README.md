# Yupi: Nexus Breuk

Speelbare mobiele webgame / PWA, geoptimaliseerd voor iPhone in landscape.

## Besturing
- iPhone: virtuele joystick, Sprint en Puls
- Desktop: WASD/pijltjes, Shift en spatie

## GitHub Pages
Publiceer vanaf de `main` branch en root-map via **Settings → Pages**.

De game start via `index.html`.
